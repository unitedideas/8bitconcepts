What it does. AI Dev Board publishes AI/ML engineering jobs, company pages and salary information. Its API supports structured job search, company lookups and agent integrations.

Inspectable work. The public API overview lists the endpoints and MCP address. Its current policy says public reads are free, with hourly abuse throttling. See the API documentation for request details and current access terms.

What this demonstrates. A searchable catalog can serve a website and an agent through separate interfaces over the same records. Filters, result formats and access rules need clear contracts.

Relevant to
A recruiting, catalog or operations workflow that needs structured search and an interface other systems can use.

What it does. Not Human Search indexes public websites for agent-oriented discovery. Its published API describes search filters, site records and readiness scores.

Inspectable work. The API overview lists search, site-detail and MCP-verification endpoints. Scores follow this product's rubric. Integration decisions still require checks of the specific endpoint and response.

What this demonstrates. Discovery records and integration checks answer different questions. Keeping the source record, observation date and verification result distinct makes an integration easier to assess.

Relevant to
A service catalog or integration workflow where teams need to inspect source records and check compatibility before relying on an endpoint.

What it does. Bring Your AI helps users move and manage setup for Claude Code, Codex and Cursor. Its public product page describes migration previews, local sync, reviewed bundles and target-side snapshots.

Inspectable work. The product site explains the local workflow, compatibility, privacy boundary and current purchase options. Remote discovery and checkout are separate from local migration.

What this demonstrates. Moving configuration between tools requires explicit scope, review and recovery. The design includes previews and snapshots so users can assess a change before applying it.

Relevant to
A developer or internal tooling workflow that needs reviewed configuration changes and a recovery path.

What it does. The research archive publishes articles and dated data snapshots. A machine-readable index records article metadata, and RSS supports readers that follow updates.

Inspectable work. The public repository contains the site and publishing tools. The article index is built from page metadata. Index and overview pages are excluded from the article total.

Publication notes. Article metadata records publication dates. Read data tables with their stated snapshot dates. Email delivery remains paused.

Relevant to
A publishing workflow that needs structured records, dated sources and consistent archive updates.
